# 🏭 Smart Conveyor Belt Sorting & Stacking System

An end-to-end industrial automation project integrating **Classic Motor Control**, **Custom PCB Signal Conditioning**, and **Siemens S7-1200 PLC Programming**.

---

## 🛠️ Project Modules

### 1. Power & Classic Control Circuit
* **Software:** SimuRelay
* **Features:** Star-Delta Motor Starter with Interlock and Emergency Stop integration.

### 2. Custom PCB Design
* **Software:** Proteus Designer
* **Features:** 24V Isolation Board using Optocouplers (PC817) and LM7805 Voltage Regulation with Transient Protection.

### 3. PLC Logic & Automation
* **Software:** Siemens TIA Portal
* **Logic:** Ladder Logic with Timers (TON), Counters (CTU), and Sensors edge detection.
